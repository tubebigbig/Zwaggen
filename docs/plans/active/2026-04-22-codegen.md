# Codegen v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. **All git ops happen inside the worktree.** Never `cd` to the primary repo.

**Goal:** Ship `zwag generate ts` (and `zwag generate zod`) producing universal TypeScript types + Zod schemas + a typed client object from a `.zwag` spec — the strategic unlock for "single API contract anywhere."

**Architecture:** New `packages/cli/src/generate/` directory. Each generator is a pure function `Spec → string`. Output is piped through pinned `prettier` for determinism. Watch mode wraps the generator in a chokidar file watcher with 200ms debounce. The CLI dispatches via a nested commander subcommand (`zwag generate <ts|zod> <spec>`).

**Tech Stack:** TypeScript, vitest, commander, prettier (pinned), chokidar, zod (consumer-side dep, not bundled), `@zwaggen/core` for spec types.

**Spec:** `docs/specs/active/2026-04-22-codegen.md`

import type { Endpoint } from '@zwaggen/core';

const TS_RESERVED = new Set([
  'break', 'case', 'catch', 'class', 'const', 'continue', 'debugger',
  'default', 'delete', 'do', 'else', 'enum', 'export', 'extends',
  'false', 'finally', 'for', 'function', 'if', 'import', 'in',
  'instanceof', 'new', 'null', 'return', 'super', 'switch', 'this',
  'throw', 'true', 'try', 'typeof', 'var', 'void', 'while', 'with',
  'yield', 'as', 'implements', 'interface', 'let', 'package', 'private',
  'protected', 'public', 'static',
]);

const SAFE_IDENT = /^[A-Za-z_$][A-Za-z0-9_$]*$/;

export function safeIdentifier(name: string): string {
  if (!SAFE_IDENT.test(name) || TS_RESERVED.has(name)) {
    return `'${name.replace(/'/g, "\\'")}'`;
  }
  return name;
}

export function tagForEndpoint(endpoint: Endpoint): string {
  return endpoint.tag && endpoint.tag.length > 0 ? endpoint.tag : 'default';
}

export function pathParamNames(path: string): string[] {
  const out: string[] = [];
  const re = /\{([^}]+)\}/g;
  let m: RegExpExecArray | null;
  while ((m = re.exec(path)) !== null) out.push(m[1]!);
  return out;
}
```

import { Command } from 'commander';
import { writeFile, mkdir, readFile } from 'node:fs/promises';
import { dirname, join, resolve } from 'node:path';
import { fromJSON, type Spec } from '@zwaggen/core';
import { format } from './format.js';

async function loadSpec(path: string): Promise<Spec> {
  const raw = await readFile(path, 'utf8');
  return fromJSON(JSON.parse(raw));
}

async function writeOut(outDir: string, filename: string, source: string): Promise<void> {
  await mkdir(outDir, { recursive: true });
  await writeFile(join(outDir, filename), await format(source), 'utf8');
}

export function registerGenerate(program: Command): void {
  const gen = program
    .command('generate')
    .description('Generate code from a .zwag spec');

  gen
    .command('ts <spec>')
    .description('Generate TypeScript types + Zod schemas + (optional) typed client')
    .option('--out <dir>', 'Output directory', './zwaggen-generated')

    .option('--no-types', 'Skip types.ts')
    .option('--no-schemas', 'Skip schemas.ts')
    .option('--watch', 'Re-run on spec change', false)
    .action(async (specPath: string, _opts: { out: string; client: boolean; types: boolean; schemas: boolean; watch: boolean }) => {

Create `packages/cli/src/generate/types.ts`:

```typescript
import type {
  Spec,
  TypeDef,
  ObjectType,
  ObjectField,
  ArrayType,
  UnionType,
  LiteralType,
} from '@zwaggen/core';
import { safeIdentifier } from './helpers.js';

const HEADER = `// AUTO-GENERATED by zwag — do not edit. Regenerate with: zwag generate ts <spec>\n\n`;

export function generateTs(spec: Spec): string {
  const lines: string[] = [HEADER];
  for (const [name, def] of Object.entries(spec.types)) {
    lines.push(emitTopLevel(name, def, spec));
    lines.push('');
  }
  return lines.join('\n');
}

function emitTopLevel(name: string, def: TypeDef, spec: Spec): string {
  if (def.kind === 'object') return emitInterface(name, def, spec);
  return `export type ${name} = ${tsType(def, spec)};`;
}

function emitInterface(name: string, def: ObjectType, spec: Spec): string {
  const head = def.extends && def.extends.length > 0
    ? `export interface ${name} extends ${def.extends.join(', ')} {`
    : `export interface ${name} {`;
  const body = def.fields.map((f) => emitField(f, spec)).join('\n');
  return body ? `${head}\n${body}\n}` : `${head}}`;
}

function emitField(field: ObjectField, spec: Spec): string {
  const key = safeIdentifier(field.name);
  const optional = field.required ? '' : '?';
  return `  ${key}${optional}: ${tsType(field.type, spec)};`;
}

function tsType(def: TypeDef, spec: Spec): string {
  switch (def.kind) {
    case 'string': return 'string';
    case 'number':
    case 'integer': return 'number';
    case 'boolean': return 'boolean';
    case 'null': return 'null';
    case 'literal': return literalToTs(def);
    case 'array': return `${arrayItem(def, spec)}[]`;
    case 'union': return def.variants.map((v) => tsType(v, spec)).join(' | ');
    case 'ref': return def.ref;
    case 'object': {
      // inline object literal
      const fields = def.fields.map((f) => emitField(f, spec)).join('\n');
      return fields ? `{\n${fields}\n}` : '{}';
    }
  }
}

function arrayItem(def: ArrayType, spec: Spec): string {
  const t = tsType(def.items, spec);
  // wrap unions in parens so `(A | B)[]` not `A | B[]`
  return def.items.kind === 'union' ? `(${t})` : t;
}

function literalToTs(def: LiteralType): string {
  if (typeof def.value === 'string') return `'${def.value.replace(/'/g, "\\'")}'`;
  if (typeof def.value === 'number') return String(def.value);
  if (typeof def.value === 'boolean') return String(def.value);
  if (def.value === null) return 'null';
  return JSON.stringify(def.value);

```typescript
import type {
  Spec,
  TypeDef,
  ObjectType,
  ObjectField,
  LiteralType,
} from '@zwaggen/core';
import { safeIdentifier } from './helpers.js';

const HEADER = `// AUTO-GENERATED by zwag — do not edit. Regenerate with: zwag generate ts <spec>\n\nimport { z } from 'zod';\n\n`;

export function generateZod(spec: Spec): string {
  const lines: string[] = [HEADER];
  for (const [name, def] of Object.entries(spec.types)) {
    lines.push(emitTopLevel(name, def, spec));
    lines.push(`export type ${name} = z.infer<typeof ${name}Schema>;`);
    lines.push('');
  }
  return lines.join('\n');
}

function emitTopLevel(name: string, def: TypeDef, spec: Spec): string {
  return `export const ${name}Schema = ${zodFor(def, spec, true)};`;
}

function zodFor(def: TypeDef, spec: Spec, topLevelObject = false): string {
  switch (def.kind) {
    case 'string': return 'z.string()';
    case 'number': return 'z.number()';
    case 'integer': return 'z.number().int()';
    case 'boolean': return 'z.boolean()';
    case 'null': return 'z.null()';
    case 'literal': return zodLiteral(def);
    case 'array': return `z.array(${zodFor(def.items, spec)})`;
    case 'union': return zodUnion(def.variants, spec);
    case 'ref': return `${def.ref}Schema`;
    case 'object': return zodObject(def, spec, topLevelObject);
  }
}

function zodObject(def: ObjectType, spec: Spec, topLevel: boolean): string {
  const fields = def.fields.map((f) => emitField(f, spec)).join(',\n');
  const body = fields ? `{\n${fields},\n}` : '{}';
  if (topLevel && def.extends && def.extends.length > 0) {
    // Multi-parent: chain .extend per parent.
    const base = def.extends.map((p) => `${p}Schema`).reduce((acc, p) => `${acc}.merge(${p})`);
    return `${base}.extend(${body})`;
  }
  if (topLevel) {
    return `z.object(${body})`;
  }
  // Inline object inside another type.
  return `z.object(${body})`;
}

function emitField(field: ObjectField, spec: Spec): string {
  const key = safeIdentifier(field.name);
  const inner = zodFor(field.type, spec);
  return `  ${key}: ${field.required ? inner : `${inner}.optional()`}`;
}

function zodLiteral(def: LiteralType): string {
  if (typeof def.value === 'string') return `z.literal('${def.value.replace(/'/g, "\\'")}')`;
  if (typeof def.value === 'number' || typeof def.value === 'boolean') return `z.literal(${def.value})`;
  if (def.value === null) return 'z.null()';
  return `z.literal(${JSON.stringify(def.value)})`;
}

function zodUnion(variants: TypeDef[], spec: Spec): string {
  // Special case: all-string-literals → z.enum(...)
  const allStringLits = variants.every((v) => v.kind === 'literal' && typeof (v as LiteralType).value === 'string');
  if (allStringLits) {
    const values = variants.map((v) => `'${(v as LiteralType).value}'`).join(', ');
    return `z.enum([${values}])`;
  }
  const inner = variants.map((v) => zodFor(v, spec)).join(', ');
  return `z.union([${inner}])`;
}
```

```typescript
import type { Spec, Endpoint, TypeDef, ResponseDef } from '@zwaggen/core';
import { tagForEndpoint, pathParamNames, safeIdentifier } from './helpers.js';

const HEADER = `// AUTO-GENERATED by zwag — do not edit. Regenerate with: zwag generate ts <spec> --client\n\nimport { z } from 'zod';\n\n`;

export function generateClient(spec: Spec): string {
  const referencedTypes = collectReferencedTypeNames(spec);
  const importLine = referencedTypes.length > 0
    ? `import { ${referencedTypes.map((n) => `${n}Schema`).join(', ')} } from './schemas.js';\n`
    + `import type { ${referencedTypes.join(', ')} } from './types.js';\n\n`
    : '';

  const groups = groupByTag(spec.endpoints);
  const groupBlocks: string[] = [];
  for (const [tag, endpoints] of groups) {
    const methods = endpoints.map((e) => emitMethod(e, spec)).join(',\n');
    groupBlocks.push(`    ${safeIdentifier(tag)}: {\n${methods},\n    }`);
  }

  return HEADER + importLine
    + OPTIONS_INTERFACE + '\n\n'
    + ERROR_CLASS + '\n\n'
    + `export function createClient(opts: ZwaggenClientOptions) {\n`
    + `  const f = opts.fetch ?? globalThis.fetch;\n`
    + `  const baseHeaders = () => typeof opts.headers === 'function' ? opts.headers() : (opts.headers ?? {});\n`
    + `  return {\n${groupBlocks.join(',\n')},\n  };\n`
    + `}\n`;
}

const OPTIONS_INTERFACE = `export interface ZwaggenClientOptions {
  baseUrl: string;
  fetch?: typeof globalThis.fetch;
  headers?: Record<string, string> | (() => Record<string, string>);
}`;

const ERROR_CLASS = `export class ZwaggenHttpError extends Error {
  constructor(public response: Response) {
    super(\`HTTP \${response.status} \${response.statusText}\`);
    this.name = 'ZwaggenHttpError';
  }
}`;

function groupByTag(endpoints: Endpoint[]): Map<string, Endpoint[]> {
  const m = new Map<string, Endpoint[]>();
  for (const e of endpoints) {
    const tag = tagForEndpoint(e);
    if (!m.has(tag)) m.set(tag, []);
    m.get(tag)!.push(e);
  }
  return m;
}

function emitMethod(endpoint: Endpoint, spec: Spec): string {
  const methodName = methodNameFor(endpoint);
  const params = pathParamNames(endpoint.path);
  const inputType = inputTypeFor(endpoint, spec);
  const ok = endpoint.responses.find((r) => r.status >= 200 && r.status < 300);
  const returnType = ok ? tsRefType(ok.type) : 'unknown';
  const parser = ok ? zodParseExpr(ok.type) : '';

  const urlExpr = buildUrlExpr(endpoint.path);
  const fetchOpts = buildFetchOptsExpr(endpoint);

  const body = `      async ${methodName}(${inputType ? `input: ${inputType}` : ''}): Promise<${returnType}> {\n`
    + `        const r = await f(\`\${opts.baseUrl}${urlExpr}\`, ${fetchOpts});\n`
    + `        if (!r.ok) throw new ZwaggenHttpError(r);\n`
    + (parser ? `        return ${parser}(await r.json());\n` : `        return undefined as unknown as ${returnType};\n`)
    + `      }`;
  return body;
}

function methodNameFor(endpoint: Endpoint): string {
  // 'list-users' → 'listUsers'; 'GET /users/{id}' → 'getUsers' — prefer endpoint.id if present.
  return safeIdentifier(camelize(endpoint.id));
}

function camelize(s: string): string {
  return s.replace(/-([a-z])/g, (_, c) => c.toUpperCase()).replace(/-/g, '');
}

function inputTypeFor(endpoint: Endpoint, spec: Spec): string {
  const parts: string[] = [];
  const pathParams = pathParamNames(endpoint.path);
  if (pathParams.length > 0) {
    const fields = pathParams.map((p) => `${safeIdentifier(p)}: string`).join('; ');
    parts.push(`{ ${fields} }`);
  }
  const queryParams = (endpoint.params ?? []).filter((p: any) => p.in === 'query');
  if (queryParams.length > 0) {
    const fields = queryParams.map((p: any) => `${safeIdentifier(p.name)}${p.required ? '' : '?'}: ${tsRefType(p.type)}`).join('; ');
    parts.push(`{ ${fields} }`);
  }
  if (endpoint.requestBody) {
    parts.push(`{ body: ${tsRefType(endpoint.requestBody)} }`);
  }
  if (parts.length === 0) return '';
  // intersect into one input
  return parts.join(' & ');
}

function tsRefType(def: TypeDef): string {
  switch (def.kind) {
    case 'string': return 'string';
    case 'number':
    case 'integer': return 'number';
    case 'boolean': return 'boolean';
    case 'null': return 'null';
    case 'literal': return typeof def.value === 'string' ? `'${def.value}'` : String(def.value);
    case 'array': return `${tsRefType(def.items)}[]`;
    case 'union': return def.variants.map(tsRefType).join(' | ');
    case 'ref': return def.ref;
    case 'object': return 'unknown'; // inline objects in endpoints not supported in v1
  }
}

function zodParseExpr(def: TypeDef): string {
  switch (def.kind) {
    case 'ref': return `${def.ref}Schema.parse`;
    case 'array': {
      if (def.items.kind === 'ref') return `z.array(${def.items.ref}Schema).parse`;
      return `z.array(${zodTypeExpr(def.items)}).parse`;
    }
    default: return `${zodTypeExpr(def)}.parse`;
  }
}

function zodTypeExpr(def: TypeDef): string {
  switch (def.kind) {
    case 'string': return 'z.string()';
    case 'number':
    case 'integer': return 'z.number()';
    case 'boolean': return 'z.boolean()';
    case 'ref': return `${def.ref}Schema`;
    case 'array': return `z.array(${zodTypeExpr(def.items)})`;
    default: return 'z.unknown()';
  }
}

function buildUrlExpr(path: string): string {
  return path.replace(/\{([^}]+)\}/g, (_, name) => `\${input.${name}}`);
}

function buildFetchOptsExpr(endpoint: Endpoint): string {
  const method = endpoint.method;
  if (method === 'GET' || method === 'HEAD') {
    return `{ method: '${method}', headers: baseHeaders() }`;
  }
  if (endpoint.requestBody) {
    return `{ method: '${method}', headers: { 'content-type': 'application/json', ...baseHeaders() }, body: JSON.stringify(input.body) }`;
  }
  return `{ method: '${method}', headers: baseHeaders() }`;
}

function collectReferencedTypeNames(spec: Spec): string[] {
  const set = new Set<string>();
  const walk = (def: TypeDef): void => {
    switch (def.kind) {
      case 'ref': set.add(def.ref); break;
      case 'array': walk(def.items); break;
      case 'union': def.variants.forEach(walk); break;
      case 'object': def.fields.forEach((f) => walk(f.type)); break;
    }
  };
  for (const e of spec.endpoints) {
    if (e.requestBody) walk(e.requestBody);
    e.responses.forEach((r: ResponseDef) => walk(r.type));
    (e.params ?? []).forEach((p: any) => walk(p.type));
  }
  return [...set].sort();
}

import chokidar from 'chokidar';
import { readFile } from 'node:fs/promises';
import { fromJSON, type Spec } from '@zwaggen/core';

const DEBOUNCE_MS = 200;

export async function watchSpec(
  specPath: string,
  onChange: (spec: Spec) => Promise<void>,
): Promise<() => Promise<void>> {
  const run = async () => {
    try {
      const raw = await readFile(specPath, 'utf8');
      const spec = fromJSON(JSON.parse(raw));
      await onChange(spec);
    } catch (err) {
      console.error(`watch: failed to regenerate — ${err instanceof Error ? err.message : String(err)}`);
    }
  };

  await run(); // initial fire

  let timer: NodeJS.Timeout | null = null;
  const watcher = chokidar.watch(specPath, { ignoreInitial: true });
  watcher.on('change', () => {
    if (timer) clearTimeout(timer);
    timer = setTimeout(() => { timer = null; void run(); }, DEBOUNCE_MS);
  });

  return async () => {
    if (timer) clearTimeout(timer);
    await watcher.close();
  };
}
```

Every response is validated through its Zod schema — if the API drifts and returns the wrong shape, you get a clear runtime error at the call site instead of a mysterious `undefined` deeper in your component tree.

## Watch mode

During development, run codegen in the background. It debounces and re-runs on every save:

```bash
zwag generate ts ./api.zwag --out ./src/generated --client --watch
```

Add it to your `dev` script:

```json
{
  "scripts": {
    "codegen": "zwag generate ts ./api.zwag --out ./src/generated --client",
    "codegen:watch": "zwag generate ts ./api.zwag --out ./src/generated --client --watch",
    "dev": "concurrently 'pnpm codegen:watch' 'vite'"
  }
}
```

## Schemas-only mode

If you only want runtime validators (e.g., your TS types come from somewhere else):

```bash
zwag generate zod ./api.zwag --out ./src/generated
```

This emits only `schemas.ts`.

## Universal runtime

Generated code uses only `globalThis.fetch`, `URL`, `JSON`, and `zod`. It runs unchanged in:

- Browsers (modern evergreen)
- Node.js ≥ 18
- Deno
- Bun
- React Native (with a fetch polyfill if your target is below RN 0.71)

There are no Node-specific imports in the generated output. Your bundler (Vite, esbuild, webpack, Rollup, …) handles the rest.

## Should I commit the generated files?

Two patterns work; pick the one that fits your team:

**Pattern A — commit them.** PRs show meaningful diffs when the contract changes. CI just runs `tsc`. Reviewers see exactly what changed type-wise.

**Pattern B — `.gitignore` them and regenerate in CI.** Keeps the repo lean. Add `pnpm codegen` to your CI's prebuild step. The trade-off: PRs don't show the type changes inline, and you need a clean spec → code pipeline.

Pattern A is more common for product teams; pattern B is more common for libraries.

## Determinism

Generated output is deterministic — same spec → byte-identical files across machines, OSes, and runs. Safe to commit, safe to compare in CI, safe to review in PRs.

## What about backend?

## Troubleshooting

**"Cannot find module 'zod'"** — `pnpm add -D zod` (or your package manager equivalent) in the project that consumes the generated code.

**"Property X does not exist on type Y"** — your spec doesn't define field X. Open the spec, add the field, regenerate.

**Tests pass but the live API returns the wrong shape** — that's drift. The generated Zod parse will throw with a precise path to the mismatched field. Fix the API or update the spec; either way the contract was wrong.
