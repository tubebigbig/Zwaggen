# Spec diff — Implementation Plan

**Spec:** `docs/specs/active/2026-04-18-spec-diff.md`

**Goal:** Pure `diffSpecs(a, b)` that categorizes changes as breaking / non-breaking. UI panel triggered from a Compare button in `AppHeader`.

---

## Tasks

### Task 1: Endpoint-level diff

**Files:**
- Create: `apps/web/src/schema/diff.ts`
- Create: `apps/web/tests/schema/diff.endpoints.test.ts`

- [ ] Export `ChangeEntry`, `SpecDiff`, `diffSpecs(a, b)`.
- [ ] Implement endpoint matching by `method + path`.
- [ ] Emit `endpoint.added` / `endpoint.removed` / `endpoint.description.changed` / `endpoint.tags.changed`.
- [ ] Implement param diff (pathParams / queryParams / headers):
  - `endpoint.param.required-added` breaking.
  - `endpoint.param.required-flipped-to-true` breaking; `to-false` non-breaking.
  - `endpoint.param.removed` breaking if was required, else non-breaking.
  - `endpoint.param.type.changed` breaking (use `JSON.stringify` equality for coarse check).
- [ ] Request body diff:
  - `endpoint.requestBody.added` breaking.
  - `endpoint.requestBody.removed` non-breaking.
  - `endpoint.requestBody.type.changed` breaking.
- [ ] Response diff:
  - `endpoint.response.added` non-breaking.
  - `endpoint.response.removed` non-breaking.
  - `endpoint.response.type.changed` breaking (per status).
- [ ] Deterministic ordering: sort by `location` within each category.
- [ ] Tests covering each kind. Identical-specs test → empty diff.
- [ ] Commit: `feat(schema): diffSpecs endpoint-level change detection`.

### Task 2: Type-level diff

**Files:**
- Modify: `apps/web/src/schema/diff.ts`
- Create: `apps/web/tests/schema/diff.types.test.ts`

- [ ] Extend `diffSpecs` to handle `spec.types` matching by name.
- [ ] Emit:
  - `type.added` non-breaking.
  - `type.removed` breaking IF the name is referenced by any endpoint in either spec, else non-breaking. (Use a ref scan similar to `buildUsageIndex`.)
  - `type.kind.changed` breaking.
  - For object types: `type.field.added.required` / `added.optional`, `type.field.removed`, `type.field.required-flipped-to-true` / `to-false`, `type.field.type.changed`.
- [ ] For non-object kinds that differ in any way (string constraints, number bounds, union variants), emit `type.changed` as breaking without drilling deeper — MVP coarse diff.
- [ ] Tests per kind string from the spec's coverage list.
- [ ] Commit: `feat(schema): diffSpecs type-level change detection`.
